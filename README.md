 🎮 Guess The Number Game 🎮
A simple browser-based Number Guessing Game built using HTML, CSS, and JavaScript :)

Features :
- Choose your own minimum and maximum range
- Random number generation
- Attempt counter
- Too High / Too Low hints
- Winning message

Technologies Used :
- HTML5
- CSS3
- JavaScript (Vanilla)

How to Play :
1. Enter a minimum and maximum number.
2. Click **Submit**.
3. Enter your guess.
4. Keep guessing until you find the correct number.

Future Improvements : 
- Play Again button
- Better UI
- Difficulty Levels
- Timer
